# bugfix

Fix a bug with a reproducible report and a regression test.

## Steps

1. Bug report summary:
   - expected vs actual
   - where it occurs (file/module)

2. Reproduction:
   - minimal steps or minimal test case

3. Root cause analysis:
   - point to exact logic and why it fails

4. Fix:
   - smallest safe change
   - no unrelated refactors

5. Add regression test:
   - must fail before fix, pass after fix

6. Handoff:
   - call /handoff
