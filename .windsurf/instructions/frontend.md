# Frontend Instructions

This file defines rules for **UI and UX**.

## Stack
- Leptos (latest stable)
- Tauri
- TailwindCSS or equivalent

## UX Rules
- Clear hierarchy
- Minimal clutter
- Football-centric visual language

## UI Responsibilities
- Render state only
- No game rules
- No simulation logic

## Performance
- Avoid unnecessary re-renders
- Use signals responsibly
- Keep state minimal

## Visual Design
- Modern
- Accessible
- Dark mode friendly
